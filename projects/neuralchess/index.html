How the engine works

Play the actual model

The real NeuralChess engine includes a playable browser interface with an evaluation bar and live search statistics. Because its inference server runs in Python, this static GitHub Pages dashboard presents verified results rather than pretending to run the trained model.

To play locally, clone the repository and run:

pip install -e .
python -m neuralchess serve --checkpoint assets/neuralchess-t2-5x48.npz --open
